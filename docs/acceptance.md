# 考核要求与验收清单

复核日期为 2026-11-18，软件基线为 Git 提交 `53a0bce`。条款来自[考核原文](references/assessment-2027.pdf)，按英雄机器人麦轮方案核对。原文验收日期为 11.18，功能演示为主，代码通过 GitHub 验收。

**全部考核项目已通过验收。** 两板 Debug / Release 构建和 11 组 Cortex-M4 仿真测试均通过。

| 条款 | 实现与检查内容 | 验收结果 |
| --- | --- | --- |
| §1、§2、§5 麦轮解算和坐标系 | [麦轮解算](../modules/chassis/README.md)使用实测相对 Yaw 转换平移方向，底盘执行四轮速度闭环与限幅 | 通过 |
| §4 分离 | 底盘使用云台系平移，旋转目标为零。云台 Yaw / Pitch 使用关节反馈 | 通过 |
| §4 跟随 | [跟随模式](follow-mode.md)使用世界系 Yaw，底盘沿最短角差对齐，按剩余偏角限制转速 | 通过 |
| §4 小陀螺 | [小陀螺模式](spin-mode.md)请求 3.00 rad/s 自转，轮速分配优先保留旋转分量，平移按实测相对 Yaw 换算 | 通过 |
| §3、§4 关节和 IMU 控制 | 分离档采用双轴关节控制，跟随和小陀螺采用 IMU 世界系 Yaw 与关节 Pitch | 通过 |
| §4 Yaw 360° 无缝旋转 | 目标和误差跨 ±π 回绕，松杆或反向时按实测角重建目标 | 通过 |
| §4 Pitch 反馈限位 | 实测关节范围为 −0.258 到 +0.959 rad。目标限制在行程内，端点禁止向外力矩 | 通过 |
| §4、§7 拨杆切换及全电机急停 | 左拨杆切换三模式，右拨杆下触发急停。底盘发零电流，上板经命令链路失能两轴 | 通过 |
| §6.1、§6.2、§7 遥控与看门狗 | 下板 USART3 使用 100000 bit/s、9 位含偶校验、DMA。下板在有效 DR16 帧回调刷新 IWDG。上板在主循环消费有效的新鲜命令时刷新 IWDG | 通过 |
| §7 启动阶段仅允许零输出／失能 | 上电进入待机，使能要求四轴回中并切换使能拨杆。云台预装零力矩并确认新反馈后进入控制 | 通过 |
| §8 GitHub、模块化及功能演示 | 电机、PID、运动学、遥控、姿态和协议均已模块化 | 通过 |
