# 考核与验证清单

以下由用户提供的考核说明整理，仅作为后续开发需求；本次初始化没有实现或验证这些功能。

## 功能

- [ ] 根据所选底盘完成速度解算与坐标变换。
- [ ] 分离模式：基于云台坐标系控制底盘运动。
- [ ] 跟随模式：底盘前向跟随云台前向。
- [ ] 小陀螺模式：保留非零旋转速度并支持平移。
- [ ] yaw / pitch 关节角度与 IMU 姿态控制。
- [ ] yaw 360° 无缝旋转；pitch 根据电机反馈限制角度。
- [ ] 拨杆切换控制模式。

## 安全与实机验证

- [ ] 遥控器数据接收 / 解包位置刷新看门狗，验证遥控器关闭后的停止行为。
- [ ] 如采用上下板通信，在对应数据解包位置实现看门狗逻辑并验证掉线行为。
- [ ] 拨杆急停使所有电机控制指令归零 / 失能。
- [ ] 启动校准期间不发送运动指令或仅发送零指令。
- [ ] 验证关节限位、输出限制和电机失联后的处理。
- [ ] 按单电机、底盘、云台、整机的顺序记录调试结果。
