# 考核要求与验收清单

复核日期为 2026-11-17，软件基线为 Git 提交 ebc26db。条款来自[考核原文](references/assessment-2027.pdf)，按英雄机器人麦轮方案核对。原文验收日期为 11.18，功能演示为主，代码通过 GitHub 验收。

**结论：尚未达到完整验收条件。** 两板 Debug / Release 构建和 11 组 Cortex-M4 仿真通过。当前固件没有上电静置或零偏标定的统一全电机门控，实机功能演示与安全验收证据仍不完整。

| 条款 | 当前工程证据 | 判定与待核验项 |
| --- | --- | --- |
| §1、§2、§5 麦轮解算和坐标系 | [麦轮解算](../modules/chassis/README.md)和底盘主循环已接入实测相对 Yaw、四轮速度环及限幅 | 软件已实现。验收记录需包含前进、横移、斜移、旋转及云台转向后的平移方向 |
| §4 分离 | 底盘使用云台系平移，旋转目标为零。云台 Yaw / Pitch 使用关节反馈 | 待演示不同云台方向下的平移及双轴独立操作 |
| §4 跟随 | [跟随模式](follow-mode.md)使用世界系 Yaw，底盘以最短角差对齐。源码记录了旧零位导致约 90° 偏差后的校正 | 待复验底盘前向与云台前向对齐、步进响应、转动中平移 |
| §4 小陀螺 | [小陀螺模式](spin-mode.md)请求 3.00 rad/s 旋转，平移按实测相对 Yaw 换算。加速度斜坡和轮速缩放会影响实际旋转 | 待演示稳定旋转、调整云台朝向、边转边走及退出 |
| §3、§4 关节和 IMU 控制 | 分离为双轴关节控制，跟随和小陀螺为 IMU 世界系 Yaw + 关节 Pitch。姿态模块解算三轴，固件只把世界 Yaw 接入闭环 | 混用已实现。若现场要求双轴世界系闭环或可独立选择关节／世界系，当前没有世界 Pitch 的固件反馈和对应拨杆入口，需向验收方确认 |
| §4 Yaw 360° 无缝旋转 | 控制误差跨 ±π 回绕，提交 f68969b 调整了分离档 Yaw 参数 | 已解决，依据用户确认 |
| §4 Pitch 反馈限位、不得堵转 | 限位取自原始位置反馈，当前为 −0.258 到 +0.959 rad。停机计时还要求输出约 25.2 N·m 以上、误差至少 0.05 rad、1000 ms 内位移不足 0.005 rad | 现有算法无法覆盖低于力矩门槛的堵转。带载抬升、上下限和异常停机缺完整实测 |
| §4、§7 拨杆切换及全电机急停 | 左拨杆切换三模式，右拨杆下触发急停。底盘发零电流，上板经命令链路失能两轴 | 软件已接入。需在运动中记录两板输出和电机实际停止。两板之间存在传播延迟 |
| §6.1、§6.2、§7 遥控与看门狗 | 下板 USART3 使用 100000 bit/s、9 位含偶校验、DMA。下板在有效 DR16 帧回调刷新 IWDG。上板解包成功且遥控有效才记新代次，主循环消费新鲜命令后刷新 | 上板刷新由解包事件驱动，调用位于主循环。若现场按字面检查调用位置，需说明该实现。待验证遥控关闭时两板停机与复位、板间断开时上板停机与复位、重连不自启 |
| §7 启动阶段仅允许零输出／失能 | 有待机回中和重新使能门控。上板联调用固定零偏，分离档可在 IMU 未就绪时工作。下板驱动门控无通用启动静置等待 | **当前启动保护缺口。** 需验证并补齐上电安全窗口及其对所有模式和电机的约束 |
| §8 GitHub、模块化及功能演示 | 电机、PID、运动学、遥控、姿态和协议均已模块化。git ls-remote 核对 GitHub main 已指向 ebc26db | 代码基线已上传。验收人员访问和正式演示结果待确认 |
