# 底盘跟随云台模式

更新日期为 2026-11-18，对应控制基线 `53a0bce`。跟随模式已接入两板。

## 操作与控制

左拨杆中位对应 `MODE_FOLLOW`。Yaw 使用 BMI088 世界航向及航向角速度闭环，
摇杆调整目标朝向，回中时捕获当前世界航向并保持。Pitch 使用关节角闭环。
底盘使用上板发送的、相对于底盘正前方标定后的 Yaw 关节角，沿最短角差转向对齐云台。
比例增益 CHASSIS_FOLLOW_KP 为 5.5，转速参考上限为 3.00 rad/s。跟随档使用 4.00 rad/s² 的角速度斜坡，并按剩余偏角提前减速。制动距离按 3.00 rad/s² 和 0.20 s 响应余量计算。相对偏角为 30° 时，制动限速约为 1.27 rad/s，约从 120° 起可请求 3.00 rad/s。
平移按实测相对角度转换，因此前推仍沿云台朝向运动。

分离档切入跟随档时捕获当前世界航向、清除 Yaw 速度环状态；退出到关节系时捕获当前
关节角，避免目标跳变。跟随与小陀螺共用世界系，互切保留航向目标。
跟随本身不累计小陀螺时长；当前小陀螺时间和转角停机保护已关闭。若重新启用，
已累计的预算不会因切入跟随而清除。

## 实机启用条件

下板不再使用 CHASSIS_FOLLOW_IMU_READY 固定禁用跟随；由上板实时检查并通过现有
状态帧报告故障。两板应配套更新，不能只更新下板而搭配旧版上板。

在 config/gimbal_setup.h 中完成实测：

1. 确认 BMI088 安装方向，配置 GIMBAL_IMU_SENSOR_TO_BODY，验证航向和角速度方向，
   再设置 GIMBAL_IMU_MOUNT_CONFIRMED=1。
2. 将云台对准底盘正前方，读取 yaw_feedback.pos * GIMBAL_YAW_DIRECTION，填入
   GIMBAL_YAW_ZERO，再设置 GIMBAL_YAW_ZERO_CONFIRMED=1。
3. 保持待机，等 `attitude_ready=1`；先检查云台抗扰和底盘正负转向，再低速验证对齐及平移。

当前 Yaw 零位为 −0.697036878 rad，IMU 使用固定零偏 0 °/s。IMU 安装和 Yaw 零位确认位均已置 1，Pitch 单轴测试已关闭。

## 故障与验证

世界姿态超过 30 ms 未更新、硬件未确认或反馈异常时，上板停机；下板通过故障状态
或板间超时停机。跨板停机存在 20 ms 状态发送周期和通信延迟。
恢复后必须回中、解除使能、重新使能，不会在保持使能时自动重启。
