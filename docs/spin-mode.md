# 常规小陀螺模式

实现日期：2026-11-16。替代原方案 A（整机随转）。软件与离线验证完成，尚未烧录、标定或实机验证。

## 操作与控制

模式拨杆 DOWN 对应 MODE_SPIN（拨杆左右以现有遥控映射为准）。进入后底盘以
1.50 rad/s 逆时针旋转（约 4.2 s/圈）；Yaw 使用 BMI088 世界航向和航向角速度闭环，保持进入时的
朝向。Yaw 摇杆可调整世界朝向，Pitch 保留关节角控制。平移仍按云台相对底盘的
实测 yaw 换算，因此底盘旋转时前推摇杆仍沿云台朝向运动。

进入/退出小陀螺时捕获新坐标系中的当前角度并复位 Yaw 速度环，避免把世界角误作
关节角。底盘旋转沿原有加速度斜坡变化。GIMBAL_YAW_WORLD 控制其他模式的默认
坐标系；小陀螺始终使用世界系，不需要为它把该宏置 1。

## 实机启用条件

在 config/gimbal_setup.h 中完成以下实测配置，不能直接把确认位改成 1：

1. 测量 BMI088 安装方向，填写 GIMBAL_IMU_SENSOR_TO_BODY；验证世界 yaw 和
   yaw 角速度方向、静态漂移后，设置 GIMBAL_IMU_MOUNT_CONFIRMED=1。
2. 云台朝底盘正前方，测量 yaw_feedback.pos * GIMBAL_YAW_DIRECTION，填入
   GIMBAL_YAW_ZERO，并设置 GIMBAL_YAW_ZERO_CONFIRMED=1。
3. 保持待机，等 `attitude_ready=1`。先验证云台抗扰方向及
   现有 0.3 N·m Yaw 力矩能否跟踪，再进行低速底盘联调。

当前配置已确认 IMU 航向方向和 Yaw 关节零位，允许小陀螺使用世界航向。云台联调暂用
三轴陀螺零偏 0 °/s，实机小陀螺待验证。下板所有模式都要求有效的相对 yaw。见 [跟随模式](follow-mode.md)。

## 停机与线束边界

当前已解除小陀螺累计时间和关节转角停机保护：`GIMBAL_SPIN_MAX_TIME_S` 与
`GIMBAL_SPIN_MAX_TRAVEL_RAD` 均为 0，分别表示关闭对应限制。超过原来的 4 s 或
±2 rad 不再停机。软件不再按这两项限制保护线束余量。

如需恢复限制，可将对应配置设为正数（单位 s / rad）。启用后的限制按单次使能
期间累计，切换模式不会刷新预算；退出小陀螺后仍检查已有转角预算。相邻编码器
角度通过 ±π 回绕解包，要求采样间实际转动小于 π。

世界姿态超过 30 ms 未更新、姿态计算失败、未标定、电机反馈掉线、急停或通信
超时时，上板停止并报告故障；下板收到故障状态或板间通信超时后停止。
在 Ozone 中查看上板的 `gimbal_drive.last_fault`。`GIMBAL_SPIN_TIME`（9）表示累计时间触限，
`GIMBAL_SPIN_TRAVEL`（10）表示关节转角触限；仅重新启用对应限制后可能触发。
故障码保留到下一次使能尝试。
跨板停机存在状态发送周期（20 ms）及传输延迟，不是两板同步瞬时停机。
故障恢复必须经过摇杆回中、解除使能、重新使能。
